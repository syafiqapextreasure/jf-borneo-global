# Image quality upgrade

Recreated all 12 displayed website photographs and video poster images individually with the available ImageGen tool, using the existing photographs as references. Output: 1536 × 1024 per master. The tool does not expose a model selector.

The original 405–720px-wide references were visibly soft when enlarged. These new images reconstruct detail and sometimes extend the scene. They may change faces, equipment and geometry; they are AI-enhanced recreations, not original footage. Captions, alt text and gallery/update notes identify this. Source TikTok links are unchanged.

Full-size PNG total: 36,972,010 bytes. Full-size lossless WebP total: 24,836,752 bytes (32.8% smaller). Each decoded full-size WebP was compared byte-for-byte with its PNG's RGB pixels. Responsive 768px versions reduce transfer size for smaller displays; both sizes use lossless encoding. Large high-density displays may still exceed native resolution; these are 1536px masters, not native 4K photographs.

This revision supersedes original-photo delivery descriptions in the earlier design audit. Layout, typography, network backgrounds, brand globe and service illustrations are retained.
